# 画线工具上下文色板与箭头工具设计

## 目标

参考同类高尔夫视频分析工具的右侧窄栏交互，为直线和箭头提供就近展开的横向色板，同时保持视频可见、工具职责清晰，并补充适合表达挥杆方向的箭头标注。

## 方案选择

采用“锚定式横向色板”：色板从右侧工具栏向左展开，与当前直线或箭头按钮对齐。相比系统菜单，它能直接展示全部颜色；相比常驻色板，它只在需要时出现，不持续遮挡视频。

## 工具栏结构

- 工具栏继续位于视频右侧内边缘，最大宽度 56pt。
- 顶部使用 `×` 退出画线模式，不再依赖底部绿色完成按钮。
- 工具顺序保持清晰：选择、直线、箭头、圆圈、角度、手绘、显示范围、撤销。
- 撤销轻点删除最后一笔；长按弹出“清除全部标注？”确认。
- 不增加独立垃圾桶按钮。

## 箭头工具

- 新增可持久化的箭头绘图类型。
- 用户拖动确定起点和终点，终点绘制箭头头部。
- 箭头与直线使用相同的颜色和线宽设置。
- 已保存箭头在退出画线模式、播放、重新进入项目和导出时持续显示。
- 选择工具可以选中并调整箭头的起点和终点。

## 上下文色板

- 点击直线或箭头时，五色选择条从对应按钮左侧横向展开。
- 色板包含红、黄、绿、蓝、白五种颜色。
- 选择颜色后立即更新当前颜色，并自动收起色板。
- 再次点击当前直线或箭头可重新打开色板。
- 切换到选择、圆圈、角度、手绘或显示范围时，色板立即收起。
- 退出画线模式时，色板立即收起。
- 圆圈、角度和手绘使用最后一次选中的颜色，但选择这些工具时不主动打开色板。
- 直线和箭头图标使用当前颜色显示；未激活工具仍保持足够对比度。

## 初始状态

- 进入画线模式时沿用上次选中的工具和颜色。
- 如果进入时当前工具是直线或箭头，色板随工具栏一起出现。
- 首次使用默认直线工具和白色。

## 验证

- iPhone 与 iPad 构建通过。
- 点击直线或箭头会在相邻位置显示五色色板，且不撑宽工具栏背景。
- 选择颜色后色板收起，后续绘制使用该颜色。
- 选择圆圈、角度或手绘不会弹出色板，但绘制颜色与最后选择一致。
- 箭头可以绘制、选择、调整、保存、重新载入并导出。
- 点击 `×` 后工具栏和色板同时隐藏，已绘制内容继续显示。
