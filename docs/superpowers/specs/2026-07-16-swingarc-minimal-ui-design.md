# SwingArc 极简专业 UI 设计

**日期：** 2026-07-16  
**状态：** 已确认，待实现计划

## 目标

将 SwingArc 设计为一款专业、简洁的 iPhone 视频画线与分析工具。用户打开或拍摄视频后，能快速逐帧定位、叠加姿态辅助、精确画线，并导出结果。

界面不承担训练、教学、成绩或球场记录的职责。

## 视觉原则

- 视频和标注是界面的主角；所有 UI 都为它们让出空间。
- 项目库使用浅灰中性色，避免领域化插画或营销式视觉。
- 分析工作台使用石墨黑画布，保证视频、白色界面和标注线的对比。
- 白色表示普通界面和文字；黄色表示当前播放帧、活动关键帧和主动编辑的标注；青色表示可选的自动姿态叠层。
- 不使用霓虹渐变、发光扫描线、成绩卡、AI 诊断文案或“科技仪表盘”式大指标。
- 不在任何界面出现球场、球杆类别、击球成绩、训练课程、推荐动作或高尔夫生活方式内容。

## 信息架构

### 项目库

应用启动后显示项目库。

- 顶部标题为“分析项目”，右上角为新增按钮。
- 每个项目使用视频第一帧缩略图，辅以项目名、创建/修改时间、时长、原始帧率和“已标注”状态。
- 新建动作提供两个等权入口：录制视频、导入视频。
- 项目默认名为“未命名分析”；用户可从项目菜单重命名。
- 不显示挥杆评分、球场、球杆、距离、训练建议或模型内容。

### 录制

录制页以原生相机预览为主。

- 顶部只有关闭、实际选定的帧率和前后摄像头切换。
- 画面中央可显示低对比度的完整人物构图框；它只提示取景，不评估动作。
- 底部只有主录制键；点击执行三秒倒计时后开始，录制时切换为停止键。
- 构图框可在设置中关闭。设备不支持目标帧率时，顶部显示实际回退帧率。
- 录制完成后直接创建项目并打开工作台。

### 分析工作台

工作台是项目唯一的编辑入口。

- 顶部为返回项目库、居中的项目名、导出。
- 中央是按实际视频显示区域计算的播放器和叠层画布；视频保持最大可用面积。
- 播放器下方依次为播放/暂停、前后逐帧、播放速度，以及单轨时间轴。
- 时间轴展示 Address、Top、Impact、Finish 标记；当前帧使用黄色竖线。点击标记跳转，长按可把当前帧设置为手动标记。
- 底部主模式只有“叠层”“画线”“关键帧”和撤销。默认不展开任何编辑托盘。
- “叠层”菜单提供骨架、头部轨迹、脊椎倾斜线和参考网格的独立开关；默认全部关闭。
- “画线”进入暂停状态并展开底部工具托盘，提供直线、圆、角度、轨迹、自由笔迹、颜色、粗细与撤销。
- 拖拽已创建的端点或角点时显示 2x 放大镜；松手后保存编辑并保留在当前项目。
- 退出画线模式时收起托盘，保留画面和所有标注。

## 行为和文案约束

- 自动分析只是可选视觉叠层和关键帧建议；没有评分、评级、结论、技术建议或可读诊断报告。
- Vision 未识别到人体时，仅在“叠层”菜单显示“未检测到人体”，不阻塞播放、画线或导出。
- 任何导入、录制、分析或导出失败都显示具体操作错误与重试路径，不生成假数据或默认分析结论。
- 项目和视频均保存在本地；不显示账户、同步、社区、课程或分享流。

## 复用与替换

复用现有的 AVPlayer、AVPlayerItemVideoOutput、Vision 检测、归一化画线坐标、可编辑控制点、放大镜、相册导入和相机录制能力。

替换现有的单体 ContentView 视觉结构、横屏双侧栏、右侧指标面板、AI 扫描遮罩、AI 分数报告、绿色渐变、球场/球杆/训练文案和固定高尔夫站姿引导。

最终视图边界为：项目库、录制页、分析工作台、视频视图、时间轴、叠层菜单和画线工具托盘。每个视图只管理自己的展示与交互状态，媒体、分析和项目状态由对应服务层管理。

## 验收标准

- 启动后只出现项目库及新建/导入入口；不出现任何高尔夫场景、球杆、球场、评分或教学内容。
- 打开项目后，视频在竖屏 iPhone 上明显大于所有控制区；默认界面没有侧栏和常驻工具箱。
- 用户能播放、切换 0.1x/0.25x/0.5x/1x、逐帧、拖动时间轴、设置/跳转关键帧。
- 用户能按需打开姿态叠层，或进入画线模式创建、微调和撤销各种标注。
- 放大镜仅在编辑控制点时出现；画线工具不会遮挡正常浏览视频。
- 导出视频与工作台中可见的标注、当前叠层和阶段标题一致。
