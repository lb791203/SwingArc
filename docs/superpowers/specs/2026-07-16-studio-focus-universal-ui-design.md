# SwingArc Studio Focus iPhone/iPad UI 设计

## 状态

- 日期：2026-07-16
- 设备：iPhone、iPad
- 主要用户：个人球员自助分析
- 已确认方向：Studio Focus
- 已确认视觉：浅色项目库进入深色分析工作台

本规格取代此前核心流程和分析工作台的视觉约定；识别算法仍由独立的两阶段 P1–P8 设计负责。

## 产品边界

第一版核心流程包含：

1. 本地项目库；
2. 导入视频或高速录制；
3. 视频分析工作台；
4. P1–P8 阶段结果与人工修正；
5. 保存和导出。

不加入学员、教练课程、消息、社区、球场、记分、训练内容或云端账号。界面不显示无法由真实分析证据支持的评分、评级或动作建议。

## 竞品取舍

设计参考当前同类产品的有效模式：

- V1 Golf：逐帧回放、画线和视频对比是核心工作流；避免把常用工具反复藏入菜单；
- Onform：常用标注工具贴近视频，支持高速视频和细粒度拖动；避免飞轮与画线手势抢占；
- Sportsbox 3D Golf：iPad 使用常驻检查器承载高密度阶段和姿态信息；
- DeepSwing：减少可见按钮、编辑器自动隐藏无关导航、阶段提示不打断视频；
- GolfFix：AI 结果按阶段组织，但 SwingArc 不引入评分、课程和社区层。

## 设计原则

- 视频始终是分析工作台最大、最稳定的视觉区域；打开工具或 AI 状态不得改变视频布局。
- 项目浏览使用浅色中性界面；进入分析后切换石墨黑，明确进入专注工作状态。
- 常用动作一层可达；模式设置使用原生 Sheet 或 iPad 检查器逐步展开。
- 所有状态同时使用文字、图标和颜色，不能只靠颜色表达。
- 触控目标至少 44×44pt，相邻主要触控间距至少 8pt。
- 支持 Dynamic Type、VoiceOver、降低动态效果、横竖屏和 iPad 分屏。
- 使用 SF Pro、SF Symbols、原生 Button/Menu/Sheet/NavigationSplitView 等平台控件。

## 视觉系统

### 项目库

- 背景：暖灰白；
- 卡片：白色、细边框、无强投影；
- 主文字：近黑；
- 次文字：中性灰；
- 主操作：近黑圆形新增按钮。

### 分析工作台

- 画布背景：石墨黑，不使用纯黑；
- 控制表面：深灰蓝；
- 主操作与已确认：绿色；
- 当前帧与当前工具：黄色；
- 姿态叠层：青色；
- 破坏性操作：系统红色；
- 普通标注：白色。

绿色只表示可执行主操作或真实已确认状态。黄色只表示当前上下文或待核对，不承担“成功”语义。

### 排版与间距

- 使用 SwiftUI Dynamic Type 文本样式，不写死字号作为唯一布局依据；
- 时间和帧号使用等宽数字；
- 使用 4/8pt 间距体系；
- 微交互为 150–250ms 原生缓动或弹簧；
- 降低动态效果开启时，模式切换只使用淡入淡出。

## 页面一：项目库

### iPhone

使用 `NavigationStack` 的单列项目列表。顶部为“分析项目”，右侧只有新增按钮和更多菜单。每个项目显示：

- 视频第一帧缩略图；
- 项目名称；
- 时长和源帧率；
- 已分析、待分析或已标注状态；
- 最近修改时间。

项目按最近修改排序。点击项目直接进入工作台；长按或项目菜单提供重命名和删除。

### iPad

项目库使用自适应列表或多列网格。进入工作台后，在 regular width 下项目列表成为可折叠左栏；compact width 下保持与 iPhone 相同的导航结构。

### 空状态

空状态只说明“导入或录制一段挥杆视频开始分析”，提供“导入视频”和“录制视频”两个按钮。删除网络演示入口、营销长文案和蓝红双主按钮。

## 页面二：新建项目

点击新增打开原生底部 Sheet：

- 导入视频：从照片选择已有视频；
- 录制视频：进入高速相机。

两个入口层级相同。Sheet 提供清晰关闭路径，不在弹层内追加设置、教程或订阅内容。

导入或录制完成后创建本地项目并直接进入工作台。失败时显示具体原因和重试动作。

## 页面三：分析工作台

### 固定区域

从上到下保持四个稳定区域：

1. 紧凑顶部栏；
2. 最大化视频与叠层画布；
3. 时间轴和 P1–P8；
4. 回放与模式控制。

顶部左侧返回项目库，中间为项目名和保存状态，右侧为导出及更多菜单。顶部不放 AI 报告、相机、指标或画线工具。

### 视频区域

视频保持原始比例并使用最大可用空间。默认不显示任何工具栏。缩放使用系统捏合手势，双击复位，同时提供可发现的复位动作，避免关键操作只依赖手势。

姿态叠层、标注和视频必须共享同一归一化坐标与缩放变换。

### 时间轴

时间轴显示当前时间、总时长、已播放区间、当前帧和八个阶段位置。当前帧使用黄色游标；阶段状态如下：

- `P1 ✓`：已确认，绿色轮廓和勾选；
- `P5 !`：低置信度，黄色轮廓和警示；
- `P6 未确定`：未解析，禁用底色和文字说明；
- `P4 当前`：当前阶段使用黄色实底。

iPhone compact width 使用两行四列，保证每个阶段触控目标至少 44pt；iPad regular width 使用单行八列。

点击已定位阶段跳到对应帧。未定位阶段点击后进入“设为当前帧”流程，不直接静默写入标记。

### 回放控制

底部始终可见：

- 播放速度：0.1×、0.25×、0.5×、1×；
- 后退一帧；
- 播放/暂停；
- 前进一帧；
- 画线模式；
- AI 分析。

逐帧按钮显示文字或无障碍标签，不使用难以理解的小刻度飞轮。播放和拖动时间轴不得抢占画线编辑手势。

## 画线模式

### 进入和退出

点击“画线”后：

- 自动暂停播放；
- 视频大小和位置不变；
- 右侧出现短工具栈；
- AI 入口暂时降级但不丢失分析状态。

点击绿色“完成”、再次点击“画线”、开始播放或切换项目时收起工具栈。选择工具本身不得导致工具栈意外重新展开或关闭。

### 工具栈

按顺序提供：选择、直线、圆、角度、自由笔、颜色/粗细、撤销、完成。清除进入二级菜单并要求确认，避免误触。

工具图标使用同一套 SF Symbols 线性语言。当前工具使用黄色实底；完成使用绿色。每个触控区域至少 44pt。

### 标注持续性

新建标注默认“全视频持续显示”。用户可在选中标注的属性中改为“仅当前 P 点”。退出画线模式只隐藏工具，不隐藏已画标注。

编辑控制点时保留放大镜；松手后写回项目。撤销只撤销最近一次标注变化。

## AI 分析状态

### 分析中

AI 分析不使用全屏黑色遮罩或扫描光效。iPhone 在底部控制上方显示紧凑进度卡，iPad 在右侧检查器显示：

- 当前真实阶段：定位挥杆段、逐帧提取、阶段求解；
- 真实百分比；
- 一行状态说明；
- 取消按钮。

视频仍可播放，手工画线仍可使用。新分析开始或用户取消后，旧任务不得回写结果。

### 分析结果

iPhone 使用可上拉底部 Sheet，iPad 使用右侧检查器。顶部摘要显示已确认、待核对和未确定数量，不只显示“8/8”。

每一阶段行包含：P 点、阶段名称、时间/帧号、置信状态和调整入口。点击行跳到视频帧并保留 Sheet/检查器状态。

结果页不显示动作评分、优秀/良好评级、训练建议或无证据诊断。

### 失败

失败信息必须说明原因和恢复路径，例如：

- 未检测到清晰人体：重新选择正面视频或调整裁剪；
- 找到多个挥杆段：选择要分析的时间范围；
- 杆身/球位证据不足：允许继续查看人体阶段，但 P6 保持待确认；
- 视频读取失败：重新导入。

失败不得清除手工标注。

## P 点人工修正

点击阶段先跳转；点击明确的“调整”动作后打开编辑卡。编辑卡包含：

- 阶段名称与当前置信状态；
- 当前时间和源帧号；
- 前后逐帧按钮；
- “设为当前帧”；
- 取消。

不把长按作为唯一入口。人工设置后阶段显示锁定状态；重新分析不得覆盖。

## iPad 自适应布局

### Regular width

使用三栏工作台：

- 左：可折叠项目栏；
- 中：视频、时间轴、P1–P8 和回放；
- 右：阶段详情、AI 状态、叠层和画线属性检查器。

中央视频优先获得宽度。左右栏可折叠，右检查器不覆盖视频。

### Compact width

iPad 分屏或窄窗口使用 iPhone 布局：单列工作台、两行 P 点、底部 Sheet。界面根据 size class 自适应，不通过设备型号分支。

### 方向

iPad 横屏使用三栏；iPad 竖屏在足够宽时保留右检查器并默认折叠左栏。iPhone 横屏以视频为主，工具和结果使用可收起浮层，避免固定双侧栏压缩视频。

## 保存与导出

编辑自动保存本地项目。顶部只显示“正在保存”“已保存”或“保存失败”。导出入口提供：

- 当前标注帧；
- 标注视频。

分享使用系统 Share Sheet。破坏性删除不放在工作台主菜单中。

## 组件边界

UI 实现应拆分为清晰组件：

- `ProjectLibraryView`：项目列表、空状态、新建入口；
- `NewProjectSheet`：导入和录制；
- `AnalysisWorkspaceView`：自适应工作台容器；
- `VideoCanvasView`：视频、姿态和标注坐标；
- `StageTimelineView`：时间轴和 P1–P8；
- `PlaybackControlsView`：播放、速度和逐帧；
- `DrawingToolRail`：画线模式工具；
- `AnalysisProgressCard`：非阻塞进度；
- `StageInspectorView`：结果和人工修正；
- `WorkspaceInspectorView`：iPad 右侧检查器。

媒体、识别、项目保存和导出仍由服务层管理，视图不直接执行 Vision 或文件写入。

## 可访问性

- 所有图标按钮提供 `accessibilityLabel` 和必要的 `accessibilityHint`；
- VoiceOver 顺序与视觉顺序一致；
- P 点朗读阶段名、时间、置信状态和锁定状态；
- Dynamic Type 放大后允许文字换行，不能靠缩小到不可读字号解决；
- 颜色不是唯一状态线索；
- 降低动态效果时取消缩放和滑移动画；
- 画线、逐帧、P 点修正都有可见按钮替代手势。

## 验收标准

- iPhone 项目库为浅色，分析工作台为深色；进入工作台后视频明显大于控制区。
- iPad 全屏不是放大的 iPhone，具有可折叠项目栏和常驻检查器。
- 默认工作台没有左右常驻长工具栏；画线模式才显示短工具栈。
- 退出画线模式后所有默认全局标注继续显示。
- P1–P8 在 iPhone 两行全显，在 iPad 一行全显，触控目标均不少于 44pt。
- AI 分析不遮挡视频，显示真实阶段和进度，可取消。
- P 点人工修正不依赖长按，且重新分析不覆盖人工锁定。
- 375pt 小屏、iPhone 大屏、iPad 竖屏、iPad 横屏和 iPad 分屏均无横向溢出或安全区遮挡。
- Dynamic Type 最大辅助字号、VoiceOver和降低动态效果下核心流程仍可完成。
