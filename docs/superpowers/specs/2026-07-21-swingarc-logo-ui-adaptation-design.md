# SwingArc Logo 与原生 UI 适配设计

日期：2026-07-21
状态：待用户复核
方向：Modern Pro Tour / Tour Precision

## 1. 目标

在保留现有「S 形挥杆轨迹＋球」品牌记忆点的前提下，重新绘制 SwingArc Logo，使 App Icon、启动体验与现有深色职业巡回赛 UI 成为同一套视觉系统。

成功标准：

- 在 iPhone 主屏幕的标准、深色和系统着色模式下都能一眼识别。
- 29 pt 小图标下仍能辨认 S 形轨迹与球，不依赖细小杆头或文字。
- Logo 颜色、圆角、材质和视觉重量与 `AnalysisTheme` 一致。
- 不遮挡相机或回放视频，不削弱「视频优先」的产品原则。
- 最终以 Xcode 模拟器和真实 iPhone 截图验收，不以浏览器渲染作为视觉依据。

## 2. 视觉方向

采用「Tour Precision」：克制、精准、现代、高端。避免传统球会徽章的复古感，也避免蓝青霓虹带来的通用 AI 工具感。

### 保留

- S 形挥杆轨迹。
- 轨迹末端附近的球。
- 挥杆方向与速度感。

### 重绘

- 当前粗重、卡通化的白色 S 改为具有起笔、加速和收束变化的单一挥杆弧线。
- 删除独立描边、细槽和具象杆头；下端通过轮廓收束或负形暗示球杆，不再额外堆叠图形。
- 球成为唯一高亮色，轨迹主体保持象牙白。
- 图形整体稍向视觉中心下移，抵消上方球体造成的重心偏高。

## 3. 标志构图

### App Icon 主标

- 使用 1024 × 1024 px 全幅正方形画布。
- 背景铺满画布；不得预先绘制圆角、白色四角、边框或投影。圆角由 iOS 负责裁切。
- 核心图形位于约 12% 的安全区内，避免系统遮罩切掉挥杆弧线。
- S 轨迹的最细处在 1024 px 母版中不得低于 64 px，确保缩小后不消失。
- 球直径约为画布宽度的 8%–10%，与轨迹末端保持清晰间距，不连接成感叹号形状。
- 不在 App Icon 内加入 `SwingArc` 或 `SA` 文字。

### 横向组合标

- 图形标志在左，`SWINGARC` 在右。
- 字标使用紧凑、略宽字面和适度字距，气质接近职业赛事计分系统。
- 英文字标只用于 App 内品牌区域和对外素材；中文功能标题继续使用现有系统字体。

### 单色标

- 提供纯白与纯黑两个单色版本。
- 单色版本不得依赖渐变、透明叠色或球体光效维持识别。

## 4. 色彩与材质

Logo 直接复用产品主题，不建立第二套品牌蓝色。

| 用途 | 色值 | 对应主题 |
| --- | --- | --- |
| 主背景 | `#090D0C` | `proTourBackground` |
| 表面辅助 | `#131917` | `proTourSurface` |
| 轨迹主体 | `#F2F5ED` | `proTourPrimaryText` |
| 球／信号色 | `#C7F038` | `proTourSignal` |
| 深绿辅助 | `#1F5E45` | `proTourGreen` |

材质规则：

- 标准版以近乎纯色的深墨绿为底，可使用非常轻微的中心明度变化，但不得形成高亮蓝色渐变。
- 轨迹保持平面、锐利、无金属描边。
- 球可使用轻微内外明度差增强聚焦，但缩小后必须仍表现为完整实心圆。
- 不使用高光玻璃、3D 球纹、复杂阴影或发光边缘。

## 5. 系统图标版本

App Icon 资源提供三种外观：

1. 标准版：深墨绿背景、象牙白轨迹、荧光草绿球。
2. 深色版：更深背景、略提高轨迹和球的局部对比，不简单降低整张图片亮度。
3. 系统着色版：使用可被 iOS 着色的单色层级，确保浅色和深色主屏幕主题均可辨认。

三种版本必须共享同一几何轮廓和光学位置，切换外观时图形不得跳动。

## 6. App 内使用

### 练习首页

- 顶部品牌区使用 28–32 pt 图形标志＋`SWINGARC` 横向组合。
- 品牌区只承担身份识别，不替代页面主标题或主要操作。

### 挥杆档案

- 空状态可使用 52–64 pt 图形标志作为视觉锚点。
- 有项目时缩小为导航区域的轻量品牌识别，不与项目缩略图竞争。

### 启动画面

- 居中使用 88–104 pt 图形标志，背景与 `proTourBackground` 一致。
- 不加入进度条、口号或复杂动画；系统启动时保持快速、安静。

### 回放、分析与相机

- 视频区域内不得添加 Logo 水印或装饰性品牌层。
- 如导航栏需要品牌识别，只使用不超过 22 pt 的单色图形标志。
- Logo 不得挤占 P1–P8、参数选择、全屏视频或相机取景面积。

## 7. 资产与组件边界

- `AppIcon.appiconset`：标准、深色、系统着色三套 1024 px 母版。
- `SwingArcMark.imageset`：App 内图形标志，优先使用矢量 PDF 或等价可缩放资源。
- `SwingArcWordmark.imageset`：横向组合标，仅在指定品牌区域使用。
- `BrandMarkView`：统一控制尺寸、颜色版本和无障碍标签，页面不得各自复制布局数值。
- `AnalysisTheme`：继续作为颜色事实来源，Logo 组件不得自行创建近似颜色。

## 8. 无障碍与小尺寸要求

- 图形标志在标准背景上的主要轮廓满足清晰的明暗对比。
- 颜色不是唯一识别手段；单色模式仍保留球与轨迹的空间关系。
- 29 pt、40 pt、60 pt、120 pt 四个尺寸逐级检查边缘、间距和重心。
- App 内装饰性标志隐藏重复朗读；承担品牌识别时无障碍名称为 `SwingArc`。

## 9. 原生验收

必须在真实原生渲染中检查以下画面：

- iPhone 主屏幕：标准、深色、系统着色三种图标外观。
- 练习首页：品牌区与主操作共存。
- 挥杆档案：空状态和有项目状态。
- 回放分析：确认没有 Logo 覆盖视频或挤压操作区域。
- 相机取景：确认 Logo 不进入取景画面。
- 实体 iPhone：检查 OLED 深色背景、荧光球亮度和小尺寸清晰度。

每个画面使用 Xcode 模拟器或实体 iPhone 截图复核。浏览器预览只能用于文件传递，不作为验收证据。

## 10. 非目标

- 不改变 `SwingArc` 产品名称。
- 不重做既有页面信息架构。
- 不增加启动动画、声音 Logo 或视频水印。
- 不借此次工作修改 P1–P8、相机、分析算法或反馈逻辑。
- 不恢复旧蓝色作为第二套主题色。
