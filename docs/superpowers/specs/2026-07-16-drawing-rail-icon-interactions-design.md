# 画线工具栏图标与清除交互设计

## 目标

让画线工具栏的每个图标只表达一个主要动作，消除“选择图标不可见”和“显示范围按钮同时承担清除功能”的歧义，同时保持右侧 56pt 窄栏不变。

## 交互定义

### 选择工具

- 使用在 iPhone 与 iPad 上均可稳定显示的手指选择图标。
- 点击后进入选择模式，可选择并调整已有标注。
- 当前激活时继续使用黄色背景表示选中状态。

### 直线工具

- 使用单条横线图标，不再使用三条横线图标。
- 点击后进入直线绘制模式。

### 标注显示范围

- 范围按钮只负责切换标注显示范围，不再包含清除功能。
- 单击在“全视频显示”和“仅当前 P 点显示”之间直接切换。
- 全视频状态使用矩形画面图标；当前 P 点状态使用图钉图标。
- VoiceOver 标签必须说明当前状态以及点击后的结果。

### 撤销与清除

- 单击撤销按钮：删除最后一笔标注。
- 长按撤销按钮：显示“清除全部标注？”确认对话框。
- 用户确认后删除全部标注；取消时不修改任何标注。
- 清除全部不再占用独立图标，工具栏高度不增加。

## 布局约束

- 工具栏继续位于视频画面右侧内边缘，距右边 10pt，垂直居中。
- 工具栏最大宽度保持 56pt。
- 不增加新的常驻按钮，不扩大视频遮挡面积。
- 点击绿色完成按钮后退出画线模式并隐藏工具栏。

## 验证

- iPhone 与 iPad 构建通过。
- 选择、直线、范围、撤销、完成图标均可见。
- 单击撤销只删除最后一笔。
- 长按撤销必须先显示确认对话框，确认后才清除全部。
- 范围按钮菜单中不再出现清除操作。
