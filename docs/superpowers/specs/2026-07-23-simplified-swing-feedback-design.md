# SwingArc 简化挥杆反馈设计

**日期：** 2026-07-23  
**状态：** 已确认

## 目标

SwingArc 的结果页专注于挥杆动作分析，不做竞品式的复杂自定义矩阵，也不把底层算法参数直接堆给用户。

每次分析默认显示一个“本次重点”和五项固定反馈。用户首先看到明确结论；需要核对时，才展开对应 P 阶段、视频画面和二维轨迹证据。

## 固定信息架构

### 本次重点

页面顶部只显示一个最值得优先改进的问题：

- 标题：动作问题或“本次动作整体稳定”
- 说明：一句基于画面证据的观察
- 建议：一句可执行的练习建议
- 证据：涉及的 P 阶段

主结论仅从证据充分且置信度合格的五项反馈中选择。排序依次考虑严重程度、证据置信度和阶段重要性；证据不足的项目不能成为负面主结论。

### 五项固定反馈

| 项目 | 主要阶段 | 分析内容 |
|---|---|---|
| 准备姿势 | P1 | 身体对齐、脊柱姿态、膝部弯曲、手位 |
| 身体稳定 | P2–P7 | 头部、脊柱与髋部的二维位移和稳定性 |
| 手部路径 | P2–P7 | 双手中心的连续二维运动路径 |
| 挥杆平面 | P2、P3、P5、P6、P8 | 手部路径、杆身投影及对应动作阶段 |
| 击球与释放 | P6–P8 | 杆身、杆头、球位及身体动作的时序配合 |

每张卡默认只显示：

- `良好`、`需注意` 或 `证据不足`
- 一句动作结论
- 对应的 P 阶段标签

结果页不提供项目开关、阶段选择矩阵或 DTL / Face-On 切换。机位由录制或导入流程确定。

## 展开层级

点击卡片后才显示：

1. 视频定位到相关 P 阶段；
2. 对应的人体、手部、杆身或杆头二维轨迹；
3. 必要的少量二维数据及其单位；
4. `实测`、`估算`、`无法识别`的证据状态；
5. 已有的可移动手动修正入口。

默认界面不显示长指标列表。内部计算结果只服务于五项反馈和证据展示。

## 数据与组件边界

数据流为：

`SwingAnalysisArtifact` → `SwingFeedbackAssembler` → `SwingFeedbackSummary + 5 × SwingFeedbackCard`

职责如下：

- `SwingMetricEngine`：计算有画面证据支持的二维动作量，不负责文案和 UI。
- `SwingFeedbackAssembler`：把阶段、轨迹和二维动作量合并为固定五项反馈。
- `SwingFeedbackSummary`：按确定性规则选出一个“本次重点”。
- `SwingTrajectoryOverlay`：只绘制当前展开项目需要的轨迹，并区分实测、估算和缺失。
- `AnalysisWorkspaceView`：显示摘要和五张固定卡，不包含自定义矩阵。

底层仍保存版本化逐帧观察结果和手动修正。重新分析时，手动值优先，不能被自动结果覆盖。

## 动作指标范围

保留用于动作分析的二维信息：

- 上杆时间、下杆时间和节奏比；
- 可见手臂与膝部关节角度；
- 头部与髋部相对位移；
- 手部与杆头二维路径；
- 杆身二维投影角；
- 二维挥杆平面代理；
- 二维髋肩分离代理。

以下内容不检测、不进入结果页：

- 真实杆头速度；
- 攻角；
- 杆面角；
- 动态杆面倾角；
- 球速、起飞角、旋转和飞行距离。

旧数据模型可以保留兼容枚举值，但新的分析输出和 UI 必须过滤这些非动作分析项目。

## 证据不足与降级

- P2、P6、P8 缺少实测杆身证据时，对应反馈显示证据不足。
- P7 缺少实测杆头与球位，且没有独立球变化事件时，不生成击球结论。
- 估算点可以用虚线帮助查看连续性，但不能作为实测判断依据。
- 低于置信度门槛、被遮挡、出画或缺失的点不能生成负面动作结论。
- 某一项目证据不足不影响其他项目正常显示。
- 输入机位、人物覆盖或画质不合格时，沿用现有具体重拍提示。

## 视觉与交互

- 延续 SwingArc 深色界面和荧光主题色，不复制竞品的浅色蓝色风格。
- 五张卡保持同一视觉层级，只有状态和当前展开项使用主题色。
- 页面默认信息量必须能在竖屏工作台中快速浏览；轨迹细节放在展开层，不在首屏堆叠。
- P 阶段标签只用于定位证据，不做可配置按钮组。
- VoiceOver 应读出项目名、状态、结论和“实测 / 估算 / 无法识别”。

## 验证标准

1. 结果模型始终产生且只产生五个固定项目。
2. 非动作分析参数不会出现在新分析输出或结果页。
3. 默认卡片不显示原始指标列表。
4. 展开卡片只显示该项目所需轨迹和 P 阶段。
5. 缺少 P2、P6、P7 或 P8 的必要物体证据时，只降级受影响的项目。
6. 估算轨迹不能触发 `良好` 或 `需注意`结论。
7. 手动修正保存后，重新分析仍保留手动值。
8. iPhone 竖屏工作台不增加页面级无意义滚动空间。
9. 模拟器整包构建、持久化回归、轨迹展示回归和 VoiceOver 标签检查均通过。

## 非目标

- 不制作竞品式 Customize 页面。
- 不允许用户逐项配置每个 P 阶段。
- 不在本阶段加入云端分析或上传原始视频。
- 不把开发数据上的结果宣传为已达到最终准确率。
