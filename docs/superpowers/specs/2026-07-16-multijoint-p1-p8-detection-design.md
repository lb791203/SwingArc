# SwingArc 多关节 P1–P8 精准定位设计

**日期：** 2026-07-16  
**状态：** 已确认，待实现计划

## 目标

使用 Apple Vision 已识别的多关节姿态数据，提高 P1–P8 挥杆阶段定位的准确性。自动结果必须来自真实采样帧；无法充分确认时应标为待确认，而不是补造阶段。

## 范围

本阶段只改善 P1–P8 定位，不输出早期伸展、过度上杆或击球质量等动作问题诊断。所有处理保留在设备本地，保留现有人工校正流程。

## 输入与采样

扫描时为每个有效视频帧保存：时间戳、双手腕、双肘、双肩、双髋、头部、肩髋中点、脊椎角和每个关节的 Vision 置信度。

缺失单一关节不丢弃整帧；该帧仍可参与支持其余特征的阶段判定，但相应阶段的证据分数下降。采样必须覆盖挥杆的短运动区间，并保留真实帧时间戳。

## 阶段状态机

检测器按时间顺序推进，任何候选阶段必须晚于前一已确认阶段。候选均引用实际采样帧。

| 阶段 | 必需证据 |
| --- | --- |
| P1 | 身体、头部和脊椎在稳定窗口内；双手低位。 |
| P2 | 手部开始持续上移，肩部旋转趋势成立。 |
| P3 | 手部和肘部继续上移，手臂进入上杆中段。 |
| P4 | 手部高度达到上杆峰值，之后出现可测的反向运动。 |
| P5 | 手部回落，肩髋转动方向和时间顺序连续。 |
| P6 | 手部进入髋部/击球区域，手部速度峰值与身体转动同时满足。 |
| P7 | P6 后手部重新上移，随挥方向成立。 |
| P8 | 手部、头部和脊椎在连续窗口内稳定。 |

## 置信度与人工校正

每个阶段返回 `已确认`、`低置信度` 或 `待确认`，并保留其证据分数。低置信度阶段可显示候选位置，但不得视为已确认。用户手动设定或移动的阶段为锁定真值，后续自动分析不得覆盖。

## 验收与测试

- 阶段时间严格递增，且每个自动阶段映射到真实采样帧。
- 为稳定挥杆、短暂停顿、关节遮挡、快挥、慢挥和无人体样本建立回归测试。
- 对人工标注的侧面挥杆样本，自动阶段与人工阶段的误差应在可配置的帧窗口内评估。
- 证据不足时返回待确认，不得用固定时间比例补齐 P1–P8。
- 人工锁定阶段在重新分析、保存和重新打开项目后保持不变。
