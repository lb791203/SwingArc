# SwingArc iPhone 挥杆分析 App 设计

**日期：** 2026-07-16  
**状态：** 已确认，待实现计划

## 目标

为高尔夫球员提供一款原生 iPhone App，用于自行拍摄或导入挥杆视频、即时慢动作复盘、自动姿态辅助分析、手动绘制挥杆分析线，以及导出带标注的视频。处理和项目数据均保留在设备本地。

## 首版范围

- 使用 iPhone 相机录制挥杆，优先使用设备可稳定支持的 120/240fps 格式，并提供起杆对齐网格与三秒倒计时。
- 从系统相册导入视频；录制与导入进入同一分析工作台。
- 0.1x、0.25x、0.5x、正常速度播放，逐帧前后步进、时间轴拖动和选段循环。
- 使用 Apple Vision `VNDetectHumanBodyPoseRequest` 按当前需要识别视频帧，显示骨架、头部轨迹和身体/脊椎倾斜线。
- 自动提出 Address、Top、Impact、Finish 阶段；用户能跳转、校准或覆盖每一个自动结果。
- 绘制并编辑直线、挥杆平面线、头部圆/轨迹、倾斜线、三点角度和自由笔迹。编辑端点或角顶点时显示 2x 局部放大镜。
- 将视频、阶段、分析缓存、标注和播放偏好保存为可继续编辑的本地项目。
- 导出带标注、分析叠层、阶段标题和所选慢放速度的视频；原始视频不改动。

## 非目标

- 首版不需要账户、云同步、多人共享或服务端 AI。
- 首版不承诺自动动作诊断或击球质量评分；自动化仅辅助定位姿态和关键阶段，用户始终可手动修正。

## 架构

### 媒体入口

`Capture` 用 AVFoundation 配置摄像头，枚举格式并选择目标帧率可用的最高稳定格式。录制结果输出为本地视频资产。

`Library Import` 使用系统相册选择器导入视频。导入视频和相机录制视频均归一为 `AVAsset`，再创建同一种 Swing Project。

### 回放与实时分析

`AVPlayer` 负责显示、速度、暂停、逐帧和时间轴控制。`AVPlayerItemVideoOutput` 在播放、暂停、逐帧或用户停止拖动后提取当前展示时间对应的视频帧。

`VisionPoseDetector` 在后台队列执行 `VNDetectHumanBodyPoseRequest`。返回的关节以视频标准化坐标与精确时间戳缓存。分析任务必须可取消或丢弃过期结果，不能延迟播放器和触控响应。

当用户处于连续播放或拖动中，只分析当前帧和必要的节流帧。用户停止操作、暂停、保存项目或明确请求分析时，后台补全四个候选阶段附近的采样，以提高阶段结果的稳定性。

### 挥杆分析

`SwingAnalyzer` 根据头、肩、髋等 Vision 关节生成：

- 骨架叠层；
- 头部位置和轨迹；
- 由肩髋中轴计算的身体/脊椎倾斜线和角度；
- Address、Top、Impact、Finish 的候选时间点与置信状态。

自动识别永远是可编辑建议。用户修改关键帧后，以用户结果为项目真值，后续分析不得覆盖。

### 标注画布

所有绘图和 Vision 叠层使用相对视频尺寸坐标存储，渲染时根据视频显示区域换算。这样横竖屏、不同显示尺寸、导出视频均使用同一套坐标。

`DrawingOverlay` 管理工具选择、命中测试、撤销/重做和标注层。拖拽端点或角点时显示 2x 放大镜，并保持手指下方的原图与叠层对齐。

### 项目存储和导出

每个项目保存视频资产引用或私有副本、视频元数据、阶段标记、绘图元素、分析缓存以及用户播放偏好。项目能够重新打开并继续编辑。

`ExportRenderer` 读取原始资产，按照导出时选定速度逐帧合成标注、可见分析层和阶段标题，再以 `AVAssetReader/AVAssetWriter` 写入新视频。导出不更改原始视频。

## iPhone 交互

首页只有三个主入口：开始拍摄、导入视频、我的挥杆。

拍摄页以竖屏单手操作为优先，在录制开始前提供对齐网格和三秒倒计时。完成录制或导入后直接进入复盘页。

复盘页的主要区域显示视频；底部提供可缩放时间轴、四个阶段按钮、播放速度、逐帧前后按钮和循环选段控制。阶段按钮可跳转，长按允许用户手动校准自动阶段。

画线模式提供直线、挥杆平面线、头部圆/轨迹、身体倾斜线、角度、自由笔迹、撤销和重做。普通播放不会被分析或标注阻塞。

## 异常与降级

- Vision 未检测到人体、置信度过低或分析仍在进行时，展示简短状态，不中断回放与手动标注。
- 导入的素材方向、帧率或编码不理想时，按资产的实际方向和时基渲染；高帧率功能不承诺用于不支持它的导入素材。
- 设备不支持 120/240fps 时，相机回退到最高可用帧率，并在开始录制前明确显示。
- 导出失败、磁盘空间不足或相册权限被拒绝时，保留项目状态并提供可重试的错误提示。

## 验收与测试

- 在真实 iPhone 上验证高帧率格式选择、录制、回放和媒体保存。
- 覆盖相册导入的横屏、竖屏、普通帧率和高帧率样本。
- 验证快速拖动、逐帧、播放速度切换期间 UI 流畅，且过期 Vision 结果不会覆盖当前帧。
- 验证标注与姿态在不同方向和尺寸下准确对齐，保存并重新打开后不漂移。
- 验证用户校正的阶段不被后台分析覆盖。
- 对比编辑预览和导出结果，确认画线、轨迹、角度、速度和阶段标题一致。
- 验证权限拒绝、无人体、低帧率和导出失败均可恢复。
